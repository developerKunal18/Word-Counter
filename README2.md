# Word Counter

## Overview
The **Word Counter** is a simple Python command-line application that analyzes user-entered text and provides basic statistics.

It counts the total number of words, characters, and lines, making it a useful utility for text analysis and practice with strings.

---

## Features
- Counts total words
- Counts total characters
- Counts total lines
- Accepts multi-line input
- Simple and beginner-friendly

---

## Technologies Used
- Python
- String methods
- Loops
- User input handling

---

## How It Works
1. User enters multiple lines of text  
2. Typing `END` stops input  
3. Program processes the text  
4. Word, character, and line counts are displayed
